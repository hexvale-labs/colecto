# Oneko

The sprite sheet for the Oneko example, kept for its rewrite as the first `ui.canvas`
extension (see [Extension UI model](../../ui-model.md#canvas)). The Wasm overlay version
was removed with the old extension system; until the rewrite there is no Oneko package.

The 32×32 sprite sheet is adapted from
[adryd325/oneko.js](https://github.com/adryd325/oneko.js), copyright 2022 adryd, MIT
licensed (see LICENSE-oneko). The original GIF was converted losslessly to PNG.
