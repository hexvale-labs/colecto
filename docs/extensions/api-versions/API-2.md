## Notes

API 2 is identical to [API 1](API-1.md). It adds nothing, removes nothing and changes
nothing. It marks the point where version numbers start meaning something: every later
change to the extension API gets the next number. Extensions on API 1 keep working
unchanged. Moving to API 2 means changing only `api_version`.
