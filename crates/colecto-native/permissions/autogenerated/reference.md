## Default Permission

Lets Colecto's own page ask for press feedback (a click sound and haptics).

#### This default permission set includes the following:

- `allow-press`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`colecto-native:allow-press`

</td>
<td>

Enables the press command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`colecto-native:deny-press`

</td>
<td>

Denies the press command without any pre-configured scope.

</td>
</tr>
</table>
